# Documentation from the repo

This minimal site demonstrates Part 1 Demo 2: Markdown in `docs/` becomes a
published site via MkDocs.

## Live demo

1. Open `docs/what-we-ship.md` and add one sentence about your team.
2. Run `mkdocs serve` from the `demos/doc-publishing` directory (see repo README).
3. Refresh the browser — docs stayed in sync with code.

For the full pyds project layout (pixi, tests, CLI), use
[`examples/pyds-init-demo`](../../examples/pyds-init-demo/).
