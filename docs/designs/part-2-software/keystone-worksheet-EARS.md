# Keystone Worksheet — EARS

**Parent LLD**: [Part 2 LLD](./LLD.md)  
**Artifact**: `resources/keystone-worksheet.md` (printable or PDF)

## Worksheet Content

- [ ] **ART-P2-KEY-001**: The keystone worksheet shall include the individual prompt: write one change that is **high pain relief, low effort**.
- [ ] **ART-P2-KEY-002**: The worksheet shall list example keystone changes: standardize artifact type, adopt `pyds project init` for new repos, migrate off conda, require docs in repo.
- [ ] **ART-P2-KEY-003**: The worksheet shall include space for pair-share notes (optional neighbor comparison).
- [ ] **ART-P2-KEY-004**: The worksheet shall include a **Monday conversation script** template attendees can use with their team.
- [ ] **ART-P2-KEY-005**: The Monday script shall reference proposing one or two technical artifacts the team always ships.

## Anchor Stories (Facilitator Reference)

- [ ] **ART-P2-KEY-010**: The worksheet file or an appendix shall include brief anchor stories presenters may offer if the room is quiet: pixi migration, standardizing shipping format.
