# BioIT Workshop Demo

Representative documentation from a pyds-scaffolded project. Part 1 Demo 2 shows
docs publishing from the repo — edit a page, rebuild, publish.

## Quickstart

```bash
pixi install
pixi run -e docs serve-docs
```

Open the local URL MkDocs prints (usually http://127.0.0.1:8000).

## Why docs live in the repo

When documentation is versioned alongside code, collaborators — and later,
coding agents — can find install steps, assumptions, and outputs in one place.
