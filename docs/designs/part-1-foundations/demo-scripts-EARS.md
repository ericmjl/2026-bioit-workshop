# Part 1 Demo Scripts — EARS

**Parent LLD**: [Part 1 LLD](./LLD.md)

## Demo Tone

- [ ] **P1-DMO-001**: Part 1 demos shall use aspirational narration ("what good looks like"), not step-by-step installation instructions.
- [ ] **P1-DMO-002**: Part 1 demos shall be observe-along; the lead shall not require attendees to install tools during Part 1.

## Demo 1: Frictionless Project Start

- [ ] **P1-DMO-010**: Demo 1 shall scaffold a new repo from a template (cookiecutter, copier, or equivalent).
- [ ] **P1-DMO-011**: Demo 1 shall visibly show what the template encodes: directory layout, CI stub, docs config, testing stub.
- [ ] **P1-DMO-012**: The lead shall narrate: "On a team that has its act together, the first commit is already aligned with team standards."
- [ ] **P1-DMO-013**: Demo 1 shall complete within 7 minutes.
- [ ] **P1-DMO-014**: If live demo fails, the lead shall switch to a pre-built repo or screen recording fallback.

## Demo 2: Docs From Code

- [ ] **P1-DMO-020**: Demo 2 shall show documentation publishing from the repo (MkDocs, Sphinx, or GitHub Pages pattern).
- [ ] **P1-DMO-021**: Demo 2 shall show at least one edit → publish cycle (live or pre-recorded).
- [ ] **P1-DMO-022**: The lead shall narrate: "When docs live in the repo, they're always current. Collaborators — and later, agents — can find what they need."
- [ ] **P1-DMO-023**: Demo 2 shall complete within 3 minutes.

## Bridge Out

- [ ] **P1-DMO-030**: Before the break, the lead shall deliver the bridge-out script: good looks like frictionless starts and docs from code → after break, practices and one change to make first.
- [ ] **P1-DMO-031**: Part 1 shall hard-stop at 45 minutes to begin the 15-minute break.

## Prep Verification (Dry Run)

- [ ] **P1-DMO-040**: The template repo or CLI shall be tested end-to-end on the presenter's machine before the workshop.
- [ ] **P1-DMO-041**: The doc publishing demo shall be deployable or showable in under 2 minutes.
- [ ] **P1-DMO-042**: Fallback artifacts (pre-built repo, screen recording, published URL) shall exist before the workshop.
